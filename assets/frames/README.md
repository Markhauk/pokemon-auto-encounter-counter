# Generation 3 interface frame assets

These 40 x 40 PNGs are transparent nine-slice border assets derived from the
corresponding 240 x 160 Pokemon Ruby, Sapphire, and Emerald frame-option
screenshots. They retain the original corner pixels and a repeating edge tile;
the screenshot interiors and text are not included.

The source screenshots are published by Bulbagarden Archives as game fair-use
images:
